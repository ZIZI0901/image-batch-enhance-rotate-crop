# 图像批量增强旋转剪切

在生物成像、材料科学及工业检测等领域，常需对采集到的图像进行标准化预处理，以提取目标区域的有效信息。本工具针对需要围绕图像中最亮区域（灰度最大值）进行旋转与裁剪的批量化处理需求而设计。它集成了图像增强、基于最亮点的自动旋转、以及后续裁剪功能，支持用户通过图形界面（GUI）进行交互操作，并允许通过修改配置文件灵活调整各处理步骤的参数与算法，为科研与工程人员提供了一套高效、可扩展的图像预处理解决方案。



## 使用说明

+ 本程序适合处理需要围绕图像最亮区域（灰度值最高）进行旋转裁剪的批量化图像处理。

+ 运行主程序文件 `main_ui.py`，即可进入图形用户界面进行操作

---

## 功能说明

##### 1. 图像增强（`image_enhancement.py`）

在旋转与裁剪之前，可对图像进行预处理增强，以突出目标光斑、抑制噪声。默认提供若干基础增强算法（如对比度拉伸、直方图均衡化等），用户可通过修改 `image_enhancement.py` 文件自定义或替换增强算法，适应不同实验条件下的图像特点。

##### 2. 图像旋转（`image_rotation.py`）

旋转中心默认选取图像中灰度值最高的像素点（最亮区域）。此外，用户可通过界面调整 **“头结点序号”** 参数，选择任意亮度次序的光斑作为旋转中心（例如灰度值第二高的光斑）。旋转模式包含两种：

* **自适应旋转**：若目标光斑呈线性分布（如线状结构、荧光标记的神经纤维等），程序将自动拟合其主轴线，并旋转至水平方向。

* **固定角度旋转**：直接输入所需旋转角度（以度为单位），图像将围绕选定中心点旋转指定度数。

高级用户可修改 `image_rotation.py` 文件，扩展或替换旋转算法（如基于主成分分析的定向旋转、手动指定旋转轴等）。

##### 3. 图像裁剪（`image_cropping.py`）

旋转完成后，程序对图像进行裁剪。裁剪区域的大小（宽度与高度）通过修改 `image_cropping.py` 文件中的对应变量进行设置，裁剪中心默认为旋转中心（最亮点）。该模块支持用户自定义裁剪规则（例如根据光斑尺寸自动计算裁剪框、保留固定边距等），只需编辑相应配置文件即可。

## 开发状态与注意事项

* **当前版本**：本工具尚处于功能完善阶段，核心流程已打通，但部分高级配置仍需用户直接修改 Python 源文件。

* **注意事项**：
  
  * 请确保待处理图像中至少存在一个符合要求的亮点，否则旋转中心可能无法正确定位。
  
  * 修改配置文件时，请遵循文件内注释说明，避免语法错误。
  
  * 建议在处理大量图像前，先用少量样本测试参数效果。
